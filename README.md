# Student Management System

A simple Student Management System built using Python, OOP, and file handling.

## Features

* Add Student
* View Students
* Search Student
* Delete Student
* Update Student Marks

## Technologies Used

* Python
* File Handling
* Object Oriented Programming (OOP)

## How To Run

1. Install Python
2. Run the Python file
3. Use the menu options in terminal
